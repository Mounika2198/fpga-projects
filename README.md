# FPGA Projects

A collection of FPGA projects developed in **SystemVerilog** to learn and demonstrate RTL design, pipelining, verification, timing analysis, and digital architecture.

## Projects

| Project | Status |
|----------|--------|
| 01 - Pipelined Multiplier | ✅ Complete |
| 02 - Multiply Accumulate (MAC) | ⏳Planned |
| 03 - FIR Filter | ⏳Planned |
| 04 - UART | ⏳Planned |
| 05 - FIFO | ⏳Planned |
| 06 - VGA Controller | ⏳Planned |
| 07 - Pong Game | ⏳Planned |
| 08 - 5-Stage RISC-V Processor | ⏳Planned |

## Tools

- SystemVerilog
- Vivado
- Xilinx Artix-7 (Basys 3)

## Goals

- Build reusable RTL modules
- Practice FPGA implementation
- Learn timing optimization and pipelining
- Develop a professional RTL design portfolio
